## 快速启动

```bash
# 安装依赖
npm install

# 启动前端开发服务器
npm run dev
```

浏览器打开 `http://localhost:5173`，进入 **Settings** 页面填入 API Key 即可使用。

## 工作流概览

```
Dashboard（仪表盘） →  Editor（导图编辑器） →  Quiz（知识考核）
     │                        │
     └── Settings ─────────────┘
              （全局配置）
```

三个核心页面构成闭环学习流程：

1. **仪表盘** — 管理所有项目，创建新导图
2. **导图编辑器** — 可视化查看/编辑知识结构，与 AI 协作
3. **知识考核** — 针对知识点生成考题，评估掌握程度

## 第一步：配置 AI 提供商

点击左侧边栏 **Settings** 进入设置页。

### 支持的提供商

| 提供商    | 推荐模型                              | 说明                 |
| --------- | ------------------------------------- | -------------------- |
| OpenAI    | `gpt-4o` / `o3`                       | 通用，兼容性好       |
| Anthropic | `claude-sonnet-4-20250514`            | 擅长深度推理，长文本 |
| DeepSeek  | `deepseek-chat` / `deepseek-reasoner` | 性价比高，支持思维链 |
| Local     | 任意 Ollama 模型                      | 本地运行，零费用     |

### 配置步骤

1. 选择 **Provider**（提供商）
2. 填入 **API Key**（Local 模式不需要）
3. 确认 **Base URL**（切换 Provider 会自动填充默认地址）
4. 填写 **Model Name**（模型名称）
5. 点击 **Save Configuration**

> **API Key 安全性**：密钥仅存储在浏览器 localStorage 中，不会上传到任何第三方服务器。

## 第二步：创建项目

在 **Dashboard** 页面点击 **AI Generate** 按钮。

### 方式一：AI 自动生成

1. 在弹出的对话框输入学习主题，例如："机器学习基础知识，包括监督学习、无监督学习和强化学习"
2. （可选）填写标题和描述
3. 点击 **Generate** — AI 会自动生成完整的知识树

### 方式二：手动创建

直接点击 **Continue Editing** 进入编辑器，从空白导图开始手动构建。

### 方式三：导入文件

拖拽 `.md` 或 `.json` 文件到窗口任意位置即可导入。

## 第三步：编辑导图

在 **Editor** 页面，所有知识以树形导图展示。

### 基本操作

| 操作      | 方式                     |
| --------- | ------------------------ |
| 拖拽平移  | 鼠标拖拽画布空白处       |
| 缩放      | 滚轮 / 工具栏 +/- 按钮   |
| 选中节点  | 单击任意节点             |
| 展开/折叠 | 点击节点上的展开图标     |
| 编辑文字  | 双击节点                 |
| 右键菜单  | 右键单击节点弹出操作菜单 |

### 右键菜单功能

选中一个节点后右键单击，可以：

- **Explain Concept** — AI 解释该知识点的含义（保存到节点中，下次可查看）
- **Refine Node** — AI 为该节点自动生成子节点，细化知识结构
- **Reorganize Children** — AI 重新组织该节点下的子节点结构
- **Knowledge Assessment** — 针对该节点发起考核
- **Rename / Delete / Add Child** — 基本的增删改操作

### 上下文关联

选中的节点信息会同步到 AI 聊天面板。当你提问时，AI 知道你在问哪个知识点，回答会更有针对性。

## 第四步：AI 对话

点击编辑器工具栏的 **AI Assistant** 按钮（💬），打开聊天面板。

### 你可以这样问

```
"详细解释什么是反向传播"
"为'卷积神经网络'添加子节点"
"总结整张导图的知识脉络"
"基于当前内容出 3 道选择题"
"帮我把节点文字润色得更专业"
```

### AI 能够自动操作导图

AI 不仅能聊天，还能直接修改你的导图结构：

| AI 行为  | 示例                                                                          |
| -------- | ----------------------------------------------------------------------------- |
| 添加节点 | 你说"补充 CNN 的三个典型架构" → AI 自动添加 LeNet、AlexNet、ResNet 三个子节点 |
| 删除节点 | 你说"去掉过时的知识点" → AI 删除对应分支                                      |
| 修改节点 | 你说"把标题改得更准确" → AI 直接重命名节点                                    |
| 保存解释 | AI 把详细解释写入节点，下次点击即可查看                                       |

### 推理过程可视化

如果你使用的是 DeepSeek-R1 或 Claude 等推理模型，聊天面板会显示一个半透明的 "思维追踪器" — AI 的思考过程实时可见。

## 第五步：知识考核

**Quiz** 页面是检验学习效果的核心工具。

### 考核流程

```
选择知识点 → AI 生成题目 → 逐题作答 → 查看报告
```

### 具体步骤

1. **选择项目** — 选择你要考核的思维导图项目
2. **选择知识点** — 勾选想要考核的节点（支持全选、单选）
3. **配置考核** — 选择难度预设和题目类型
4. **开始答题** — AI 为每个知识点生成针对性题目
5. **查看报告** — 完成后生成详细评估报告

### 题目类型

| 类型   | 说明                                   |
| ------ | -------------------------------------- |
| 选择题 | 从选项中选出正确答案                   |
| 判断题 | 判断陈述是否正确                       |
| 填空题 | 输入答案（自动模糊匹配，容忍拼写错误） |
| 简答题 | 自由作答，AI 评估                      |

### 掌握度系统

- 每次答完题，系统通过**贝叶斯认知模型**更新你对每个知识点的掌握度
- 掌握度用颜色直观显示：🔴 红色（低）→ 🟡 黄色（中）→ 🟢 绿色（高）
- 每个掌握度附带 **95% 置信区间**，告诉你这个评估有多可靠
- 如果不复习，掌握度会随时间自然衰减（遗忘曲线），鼓励定期回顾

## 场景示例

### 场景一：学习新知识

```
1. Settings → 配置 AI（例如 GPT-4o）
2. Dashboard → 新建项目 → AI 生成"量子计算"导图
3. 进入编辑器 → 和 AI 对话深入了解具体节点
4. Quiz → 选择知识点 → 开始考核 → 查看报告
5. 每周重复 3-4 步 → 观察掌握度逐渐变绿！
```

### 场景二：备考复习

```
1. 打开已有的学习导图
2. Quiz → 筛选"未考核概念"，聚焦薄弱环节
3. 逐题作答 → 注意置信区间（宽的表示需要更多练习）
4. 对答错的知识点，回到 Chat 让 AI 详细讲解
```

### 场景三：头脑风暴

```
1. 新建项目，中心主题设为研究问题
2. Chat → "围绕这个主题生成 10 个分支方向"
3. 查看生成的树结构 → 删除不相关的分支
4. Chat → "总结我们讨论的核心要点"
5. RAG 引擎自动索引所有内容，下次可直接检索
```

## 常见问题

### Q: API Key 存在哪里？安全吗？

API Key 只存储在浏览器的 localStorage 中。如果你使用全栈模式（有后端），AI 请求通过后端代理转发，Key 不会暴露给前端。

### Q: 本地模型怎么配置？

选择 Provider 为 **Local**，Base URL 会自动设为 `http://localhost:11434/v1`。确保本地运行了 Ollama 或兼容的 OpenAI API 服务。

### Q: 项目数据存在哪里？

默认存储在浏览器 localStorage 中。在 Settings 页面可以使用 **Export Full Backup** 导出为 JSON 文件备份。如果配置了后端，数据会同步到 SQLite 数据库。

### Q: 支持中文吗？

是的，完全支持中英文双语。在 Settings 页面可以切换语言。AI 会根据你的提问语言自动使用对应语言回答。

### Q: 导图节点太多会卡吗？

对于大型导图（数百节点），系统会自动启用性能优化模式：

- 生成时动画自动关闭（避免卡顿）
- 节点查找使用索引表（O(1) 查找）
- 树操作仅克隆路径节点（O(depth) 而非 O(n)）
