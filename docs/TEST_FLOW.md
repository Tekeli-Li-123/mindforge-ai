# 测试流程

本文档提供完整的测试流程，用于验证 MindForge AI 所有功能模块的正确性。

### 运行命令

```bash

npm test

# 监听模式（开发时使用）
npm run test:watch

# 带覆盖率报告
npm run test:coverage
```

| **合计**                 | **46** |                  |

### 验证方式

```bash
npm test
# 预期输出: Tests  46 passed (46)
```

---

## 2. 代码质量检查（自动化）

### 运行命令

```bash
# ESLint 检查
npm run lint

# Prettier 格式检查
npm run format

# ESLint 自动修复
npm run lint:fix

# Prettier 自动格式化
npm run format:fix
```

### 预期结果

- `npm run lint` — 输出 **warning/error** 均为现有代码的预知问题（非新增）
- `npm run format` — 不报格式错误

### 验证方式


## 6. 回归测试

每次修改后执行的标准验证流程：

```bash
# 1. 运行所有单元测试
npm test

# 2. ESLint 检查
npm run lint

# 3. TypeScript 类型检查
npx tsc --noEmit

# 4. 完整构建
npm run build
```

确认以上 4 步全部通过后，可安全提交代码。

---

## 7. CI 验证（GitHub Actions）

每次推送到 `main` 或 `develop` 分支，或创建 PR 到 `main` 时，GitHub Actions 自动运行：

1. ✅ 安装依赖 (`npm ci`)
2. ✅ ESLint 检查 (`npm run lint`)
3. ✅ 格式检查 (`npm run format`)
4. ✅ 单元测试 (`npm test`)
5. ✅ 构建 (`npm run build`)

可在 GitHub 仓库的 **Actions** 标签页查看运行结果。
